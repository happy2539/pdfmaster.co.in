General
PDFMaster is a free, browser-based toolkit of 21+ PDF and image conversion tools. Convert PDF to JPG, merge PDFs, split files, reorder pages, remove metadata, and more — all without uploading a single file to any server. Everything runs directly in your web browser using modern JavaScript APIs, keeping your files 100% private.
PDFMaster was founded by Happy Gupta, a student developer passionate about browser APIs and privacy-preserving technology. The project was born in 2024 out of frustration with PDF tools that forced users to upload sensitive files to unknown servers or pay for basic features. Learn more on our About page.
Three key reasons: (1) Privacy — your files never leave your device, unlike most online PDF tools. (2) Speed — on-device processing gives instant results with no upload queues. (3) Cost — completely free, with no subscriptions, paywalls, or hidden fees, ever. No account needed either.
No account, email, or registration of any kind is required. Simply open a tool and start using it immediately. PDFMaster is intentionally zero-friction — no sign-up forms, no email verification, no passwords to manage. Just open and use.
PDFMaster currently has 5 live tools covering a wide range of document needs. Our tools include Photo to PDF, PDF to Photo, Split PDF, Merge PDF (Compiler), PDF Metadata Remover, and many more. We are constantly building and releasing new tools. See the latest update on our Announcements page.

Tools & Features
Open the Photo to PDF tool: (1) Click "Browse" or drag and drop your image files onto the upload zone. (2) Reorder images by dragging if needed. (3) Choose your page size and orientation. (4) Click "Convert to PDF" — the PDF downloads instantly. Supports JPG, PNG, WebP, GIF, BMP and more.
Open the PDF to Photo tool and upload your PDF. Each page will be rendered as a high-quality image. Adjust the output quality/DPI, then download individual pages or all images at once as a ZIP file. Pages are rendered at full resolution using your browser's built-in PDF rendering engine.
Use the PDF Compiler tool. Upload two or more PDF files, drag them into your preferred order, optionally select specific page ranges from each file, then click "Compile PDF". The merged document downloads instantly. No limit on the number of PDFs you can combine.
The Split PDF tool lets you divide a PDF multiple ways: split every page into individual files, split at specific page numbers, or extract a custom page range (e.g. pages 3–7). All resulting files download as a ZIP archive immediately.
Open the PDF Reorder tool and upload your PDF. Thumbnail previews of all pages appear. Drag and drop them into your desired order, then click "Save Reordered PDF" to download the updated file instantly.
The Split PDF tool offers multiple modes: Custom Ranges (extract specific pages like 1-3, 5), Fixed Ranges (split every X pages), and Extract All Pages (save every page as a separate PDF). It provides visual page selection and downloads a ZIP file containing the split documents.
Use the PDF Metadata Remover tool. Upload your PDF and the tool strips all hidden metadata — author name, creation date, software information, geolocation tags, and other embedded properties — then lets you download the clean file. Ideal before sharing sensitive PDFs publicly.

File Support
Input formats: PDF (.pdf), JPEG/JPG, PNG, WebP, GIF, BMP, TIFF for image tools. Output formats: PDF for conversion tools, JPG/PNG for PDF-to-image tools, and ZIP archives when downloading multiple files. Support for additional formats like HEIC and SVG is being explored for future updates.
There is no server-imposed file size limit since all processing happens in your browser. Very large files (100MB+) may process more slowly depending on your device's available RAM and CPU. For best performance with large files, use a desktop or laptop with a modern browser like Chrome.
There is no hard limit on the number of files. The Photo to PDF and PDF Compiler tools let you add as many files as needed. Performance may slow on very large batches (50+ PDFs) depending on your device. On modern hardware, even large batches typically process in seconds.
Output quality is high by default. PDF tools preserve original document quality. For PDF-to-image conversions, pages are rendered at high DPI (typically 150–300 DPI). Some tools offer a quality/compression slider so you can balance file size against output quality based on your needs.
Currently, PDFMaster tools do not support password-protected or encrypted PDFs. If you try to process a locked PDF, the tool will display an error. You'll need to remove the password protection first using another tool, then process it in PDFMaster. A dedicated PDF unlock tool is on our roadmap.
PDFMaster can process scanned PDFs (treated as image-based PDFs). However, OCR (Optical Character Recognition) to extract searchable text from scanned documents is not currently supported. We're exploring adding browser-based OCR via Tesseract.js in a future update.
Errors typically occur if the PDF is: (1) password-protected — unlock it first; (2) corrupted or malformed — try re-downloading or re-exporting from the source app; (3) uses a non-standard PDF version our library doesn't fully support. If problems persist, contact us with the tool name and error details.
Technical
PDFMaster works on all modern browsers: Google Chrome (recommended), Mozilla Firefox, Apple Safari, Microsoft Edge, Opera, and Brave. Keep your browser updated to the latest version for the best performance and compatibility. Internet Explorer is not supported.
Yes. PDFMaster is fully responsive and designed for all screen sizes — smartphones, tablets, laptops, and desktops. It works on iOS Safari and Android Chrome. Some drag-and-drop features (like reordering files) may behave differently on touch screens, but all core functionality is accessible on mobile.
Modern browsers include powerful APIs for file handling and computation. PDFMaster leverages open-source libraries — PDF.js (by Mozilla, for rendering), pdf-lib (for creating/modifying PDFs), and jsPDF (for generating PDFs from images) — which run entirely as JavaScript in your browser tab. Your CPU and RAM do the processing, not a remote server.
