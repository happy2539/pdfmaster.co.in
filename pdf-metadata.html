What is PDF Metadata?

Every PDF file carries invisible data you might not know exists — and it can reveal far more than you intend when shared.

👤

Author & Identity

The name of the person or organisation that created the document — often pulled directly from your OS account name.

🕐

Creation & Modification Dates

Exact timestamps showing when the document was first created and last edited, including timezone info and revision history.

💻

Software Fingerprint

Which application generated the PDF — Adobe Acrobat, Microsoft Word, LibreOffice, macOS Preview, or others — exposing your tech stack.

📦

XMP Metadata Packets

Advanced XML-based embedded data that can hold company names, document IDs, copyright claims, camera settings, and custom enterprise fields.

🔑

Keywords & Subject

Tags and category descriptors embedded by document management systems that can expose internal filing structures and classification schemes.

🛡️

Security & Permissions

Encryption status, access restrictions, digital signature presence, AcroForm state, and PDF/X conformance markers.

FAQ

Frequently Asked Questions

Everything you need to know about PDF metadata, privacy, and how this tool works.

Is my PDF uploaded to your server? ▼
No. Everything happens entirely in your browser using JavaScript and the Web APIs. Your PDF file never leaves your device — no data is transmitted to any server. This makes PDFMaster completely private and safe for sensitive or confidential documents.
Will removing metadata affect the PDF's content or layout? ▼
Not at all. Metadata is stored completely separately from the PDF's actual content. Removing it only strips the hidden information fields — your text, images, fonts, formatting, links, and page layout remain 100% intact.
What metadata fields does this tool remove? ▼
This tool removes all standard PDF Info Dictionary fields (Title, Author, Subject, Keywords, Creator, Producer, CreationDate, ModDate, Trapped, GTS_PDFXVersion, GTS_PDFXConformance), the full XMP metadata XML stream, Adobe's PieceInfo private metadata block, and optionally all non-standard custom fields added by applications.
Why is this tool better at removing metadata than others? ▼
Many tools simply set metadata fields to empty strings, which means the keys still exist in the file and can be detected by metadata readers. PDFMaster directly deletes the keys from the raw PDF Info Dictionary using the pdf-lib library's low-level API, and also removes the full XMP stream and PieceInfo block — ensuring metadata is completely absent, not just blanked.
What is XMP metadata and why should I remove it? ▼
XMP (Extensible Metadata Platform) is an XML-based standard embedded within PDFs that can hold rich information including company names, document IDs, revision history, copyright claims, camera settings for images, and custom enterprise data. It is often far more detailed than the basic Info Dictionary, and many tools miss it entirely. PDFMaster removes the full XMP stream from the document catalog.
Is there a file size limit? ▼
There is no hard server-side limit since all processing runs locally in your browser. The practical limit depends on your device's available RAM. Most modern browsers handle PDFs up to 100 MB or larger without any issues.
Can I remove metadata from a password-protected PDF? ▼
For PDFs with an open (user) password, you will need to unlock them first. For PDFs with only an owner/permissions password — which restricts editing but not opening — metadata removal typically still works successfully, since those restrictions apply to content modifications, not metadata dictionary access.
Is this tool completely free? ▼
Yes — completely and permanently free. No registration required, no subscription, no usage limits. PDFMaster is built to provide professional-grade PDF privacy tools to everyone, for free.
